## 岸台旗号判读

首页顶部的“岸台旗号 · 分组证据与限时转向”提供两个可回放案例：

- **同色双航迹**：两条航迹看到相同的 R–Y–B 颜色片段；只有看得见升/降边界的航迹能确认 R–Y 同组，并排除交接时拼出的跨组伪令 R–Y–B。
- **迟到才可辨**：同组边界在响应截止后才出现；提前猜测可以操舵和保留航迹，但不能改变下一门线。

拖动时间轴、点击时间刻度或播放回放，再用“左舵 / 右舵”记录猜测；证据闭合且在截止前下达方向匹配的舵令后，门线才会变为生效状态。核心判定逻辑在 `src/features/signals/model/signals.ts`。
